# 第九章 综合评价方法
## 9.1 综合评价的基本理论和数据预处理
根据一个系统同时收到多种因素影响的特点, 综合考察多个有关因素, 依据多个指标对系统进行总评价的方法
介绍常用评价方法的基本原理,主要步骤,以及实际应用

### 9.1.1 综合评价的基本概念
由评价对象, 评价指标, 权重系数, 综合评价模型, 评价者 五个基本要素组成
#### 1. 评价对象
- concept: 综合评价问题所研究的对象, 或称系统
- 通常, 评价对象属于同一类, 个数要大于1, 
- 记为 $S_{1}, S_{2}, ..., S_{n} -- (n > 1)$

#### 2. 评价指标
- concept: 反应对象运行/发展的基本要素
- 通常多种指标,每种指标从不同侧面刻画系统所具有某特大小的一个度量
- 记为 向量 $\mathbf{x} = [x_{1}, x_{2}, ..., x_{m}]$ (评价指标向量, 指标体系)
- 遵循原则: 系统性, 独立性, 可观测性, 科学性, 可比性

#### 3. 权重系数
- concept: 刻画评价指标之间的相对重要性
- 记为 $\omega_{j}(j = 1, 2, ..., m)$ 表示评价指标 $x_{j}$ 的权重系数
  满足 $\omega_{j}$ >= 0, 和为1
- 评对象和评价指标值确定后, 评价结果依赖于权重系数选取(可信度, 评价正确性)

#### 4. 综合评价模型
建立一定的数学模型将多个评价指标值综合位一个整体综合评价值

### 9.1.2 综合评价体系的构建
综合评价过程包括评价体系建立,评价指标预处理,指标权重确定,评价模型选取
#### 1. 评价指标和评价指标体系
定性指标and定量指标
- 指标分类:
  极大型指标(效益型指标)
  极小型指标(成本型指标)
  居中型指标
  区间型指标

#### 2. 评价指标的筛选方法
收集--筛选
- 专家调研法
- 最小均方差法
  原理:若各个对象对某个指标的值都**差不多**,则该指标不管重要与否对评价结果作用很小
  可以删除
  (只考虑了指标差异程度,可能删除重要指标)
  方法:
  - 求第j个指标均值和均方差
  - 求最小均方差
  - 若最小均方差约为0, 可以删除对应指标, 考察完所有指标得到最终评价指标体系
- 最大最小离差法
  原理:同最小均方差, 通过最大离差反应是否**差不多**
  - 求出第j项指标的最大离差
  - 求出最小(的最大)离差
  - 若最小离差约为0, 可以删除对应指标, 考察完所有指标得到最终的评价指标体系

### 9.1.3 评价指标的预处理方法
- 不可公度性:各指标值可能属于不同类型,不同单位,不同数量级
- 预处理:综合评价时, 消除各项指标差别带来的影响
  包括一致化处理and无量纲化处理

#### 1. 指标的一致化处理
concept: 各种类型的指标一致化为同类(如极大/极小)指标
常见方向: 一致化为极大型指标
数学方法:
- 极小型指标化为极大型指标
  取倒数, 平移变化(借助该指标值中的Max)
- 居中型指标化为极大型指标
  P261.275: 公式
- 区间型指标化为极大型指标
  公式

#### 2. 指标的无量纲化处理
- 标准样本变换法(借助均值, 方差)
- 比例变换法: 极大型: aij/max, 极小型: min/aij
- 向量归一化法: 极大型指标出意根号平方和, 1-极小型/均方根
- 极差变换法: [0, 1], 最优指标1, 最劣指标0
- 功效系数法: 平移量,旋转量(放大缩小倍数)

#### 3. 定量指标的定型化
赋值--量化,0, 1
极大型指标量化方法
0, 0.3, 0.5, 0.7, 1(高). 解与两等级间取两分值间适当数值作为量化值
极小型指标量化方法
(低)0, 0.3, 0.5, 0.7, 1. 解与两等级间取两分值间适当数值作为量化值

### 9.1.4 评价指标的预处理示例
例9.1 3极大,1极小,2定性指标
量化--标准化(向量归一化, 比例变换法, 极差变换法)
``` py
# 程序文件Pex9_1.py
import numpy as np
import pandas as pd

a = np.loadtxt("Pdata9_1_1.txt")
R1 = a.copy()
R2 = a.copy()
R3 = a.copy()   # 初始化
# attention: 若 R1 = a,内存地址一样, R1改变时, a也改变

for j in [0, 1, 2, 4, 5]:       # 外循环处理不同指标,内部一句处理该指标的每个值 # 处理极大型
    R1[:, j] = R1[:, j]/np.linalg.norm(R1[:, j])    # 向量归一化
    R2[:, j] = R1[:, j]/max(R1[:, j])
    R3[:, j] = (R3[:, j] - min(R3[:, j]))/(max(R3[:, j] - min(R3[:, j])))
R1[:, 3] = 1 - R1[:, 3]/np.linalg.norm(R1[:, 3])
R2[:, 3] = min(R2[:, 3])/R2[:, 3]
R3[:, 3] = (max(R3[:, 3]) - R3[:, 3])/(max(R3[:, 3] - min(R3[:, 3])))

np.savetxt("Pdata9_1_2.txt", R1)    # 把数据写入文本,供下面使用(?)

np.savetxt("Pdata9_1_4.txt", R3)
```

## 9.2 常用的综合评价数学模型
concept: 将多个指标值综合在一起, 得到一个整体性评价指标值的一个数学表达式

### 9.2.1 线性加权综合评价模型
- 权重系数$\omega = [\omega _{1}, \omega_{2}, ..., \omega_{n}]$
  可以由专家咨询主观赋值, 或熵权法 主成分分析法等得到客观权重
- 综合评价指标: 求各指标加权和f
- 适合各指标相互独立

### 9.2.2 TOPSIS法
- 理想解的排序方法(technique for order preference by similarity to ideal solution)
- 借助于评价问题的正理想解(虚拟最佳对象)和负理想解(虚拟最差对象), 各对象与理想解的距离->优劣排序
- 计算过程步骤:
  1. 预处理: 一致化(为极大型) + 无量纲化, 构造评价矩阵B = $(b_{ij})_{m\times n}$
  2. 确定正理想解($c^{+}_{j} = max(b_{ij})$), 负理想解($c^{-}_{j} = min(b_{ij})$)
  3. 计算距离: si+, si-
  4. 计算相对接近度: si- /(si+ + si-)
  5. 按fi由大到小排序优劣次序

注: 若已知权重,可结合权重构造矩阵 $B^{'}$, 代替上文的B矩阵进行计算分析

### 9.2.3 灰色关联度分析
- 计算过程步骤:
  1. 预处理
  2. 确定比较数列/评价对象 vs 参考数列(评价标准)
  3. 灰色关联系数计算
     关联系数, 分辨系数, 两级最小差, 两级最大差
  4. 灰色关联度计算
     权重(若无则均权)x关联系数, 累加
  5. 评价分析
     关联度越大评价结果越好

### 9.2.4 熵值法
- 信息熵: 信息不确定性的一种度量
- 熵值法: 计算各指标观测值的信息熵, 根据各指标相对变化程度对系统整体的影响(由熵值来评估)来确定指标系数权重的一种赋权方法
- 计算过程步骤:
  1. 计算在**第j项指标下**第i个评价对象的特征比重
  2. 计算 第j项指标的 熵值
  3. 计算 第j项指标的 差异系数
  4. 确定 第j项指标的 **权重系数**
  5. 计算第i个评价对象的**综合评价值**: 结合权重和特征值

### 9.2.5 秩和比法
- concept: 矩阵秩转换 => 无量纲统计量RSR, 据此排序
- 样本秩: k为Ci在样本中的秩Ri, 第i个秩统计量, R1到Rn总成为秩统计量
- 计算过程步骤: 
  1. 编秩(逐列编秩, 极大型指标从小到大编秩, 极小型指标从大到小编秩)
  2. 计算秩和比(RSR)
     权重相同: 秩和/mn vs 权重不同 秩权重和/n
  3. 秩和比排序: 秩和比越大评价结果越好

### 9.2.6 综合评价示例
例9.2(续例9.1) 采用比例变换法得到评价矩阵 $R_{2}$ 作为标准化数据矩阵
以下用TOPSIS法, 灰色关联度, 熵值法, 秩和比法对战斗机性能综合评价

``` py
# 程序文件 Pex9_2.py
import numpy as np
from scipy.stats import rankdata

# TOPSIS法
a = np.loadtxt("Pdata9_1_3.txt")
cplus = a.max(axis = 0)         # 逐列求最大值
cminus = a.min(axis = 0)        # 逐列求最小值
print("正理想解 = ", cplus, "负理想解 = ", cminus)
d1 = np.linalg.norm(a-cplus, axis = 1)  # 求到正理想解的距离
d2 = np.linalg.norm(a-cminus, axis = 1) # 求到负理想解的距离
print(d1, d2)
f1 = d2/(d1+d2)
print("TOPSIS的评价值为: ", f1)

# 灰色关联度分析
t = cplus - a                   # 计算参考序列与每个序列的差
mmin = t.min()
mmax = t.max()                  # 计算最小差和最大差
rho = 0.5
xs = (mmin+rho*mmax)/(t+rho*mmax)# 计算灰色关联系数
f2 = xs.mean(axis = 1)          # 求每一行的均值-灰色关联度
print("\n关联系数 = ", xs, '\n关联度 = ', f2)   # 显示灰色关联系数和灰色关联度

# 熵值法
cs =  a.sum(axis = 0)       # 逐列求和
P = 1/cs * a                # 求特征比重矩阵
e = -(P*np.log(P)).sum(axis = 0)/np.log(n)  # 计算熵值
g = 1 - e                   # 计算差异系数
w = g/sum(g)                # 计算权重
F = P@w                     # 计算各对象评价值
print("\nP={}\n,e={}\n,g={}\n,w={},\nF={}".format(P, e, g, w, F))

# 秩和比法
R = [rankdata(a[:, i] for i in np.arange(6))]   # 求每一列的秩
R = np.array(R).T                               # 构造秩矩阵

RSR = R.mean(axis = 1)/n
print("RSR = ", RSR)
```
